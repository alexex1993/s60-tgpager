Nokia N70 в роли Telegram-пейджера: пишешь боту — сообщение приходит на телефон. Ответить можно с кнопок.

Архитектура: C++ под Symbian → TCP → Python-прокси → Telegram API. HTTPS остаётся на сервере. Два соединения разделяют приём и отправку.

Код написал LLM-агент. Из трудностей: SDK с Perl 5.6.1, кириллица через UTF-16-коды и пустые строки в списке. Последний баг исправила табуляция перед текстом — именно её ждал UI-компонент.
