# TG Pager — Telegram-пейджер для Nokia N70 (S60 2nd FP3)

Руководство на английском и прототип отдельного аудиопрокси:
[Nokia N70 microphone streaming with Codec 2](codec2/README.md)
(телефон → сервер → прослушивание в браузере).
Быстрый запуск Python-сервера на macOS/Linux: [codec2/QUICKSTART.md](codec2/QUICKSTART.md).
Промпт для будущего клиента под Windows/Symbian SDK: [codec2/WINDOWS_CLIENT_PROMPT.md](codec2/WINDOWS_CLIENT_PROMPT.md).

Клиент двусторонней связи с Telegram-ботом через собственный прокси
(телефон не умеет TLS — всю работу с Telegram API выполняет прокси на сервере).

## Сборка

```
TgPager\build.cmd   ->  TgPager.sis
```

Установка: переслать `TgPager.sis` на телефон (Bluetooth / PC Suite) → открыть →
установить. Подпись не нужна (S60 2nd без platform security). UID3 `0x70000072`.

## Настройка на телефоне

Меню → Настройки → задать:

- **Сервер** — IP или домен прокси (например `192.168.1.50` или `ddns.example.org`)
- **Порт** — порт прокси (по умолчанию `7777`)
- **Код доступа** — пароль, если на сервере задан `REQUIRE_CODE`, иначе пусто

Настройки сохраняются в `!\system\apps\TgPager\tgp.cfg` и применяются сразу
(переподключение автоматическое). При следующем запуске подключение
выполняется автоматически.

## Пользование

- **Написать** — набрать текст (кириллица поддерживается, ввод через T9/abc) →
  OK → сообщение уйдёт боту, появится в истории с префиксом `Я:`.
- Входящие от бота отображаются с префиксом `Бот:` + всплывающее уведомление.
- **Подключить/Отключить** — управление соединением; при обрыве (GPRS)
  переподключение автоматически каждые 10 с.
- **Очистить** — очистить историю.


## Ограничения (v1)

- Длина исходящего сообщения — до 200 символов, входящего — 400 (усекается сервером).
- Многострочные сообщения отображаются в одну строку (переводы строк → пробел).
- Кириллица в интерфейсе задаётся литералами UTF-16 в `inc\tgstrings.h`
  (компилятор ресурсов SDK не умеет UTF-8 исходники — см. историю проекта).
  Иконка и имя приложения ("TG Pager") — латиницей.
- Эмодзи передаются корректно (UTF-8 + суррогатные пары), но глифов в шрифте N70 нет.

## Структура

```
TgPager/
  group/   tgpager.mmp, bld.inf
  src/     tgpagerappui.cpp      меню, диалоги, наблюдатель движка
           tgpagerappview.cpp    список сообщений (листбокс + перенос строк)
           tgpagerengine.cpp     TCP-движок: 2 соединения (poll long-poll + send), DNS, ретраи
           tgsettings.cpp        сохранение настроек
  inc/     tgstrings.h           русские строки (UTF-16 кодпоинты)
           tgutf.h               UTF-8 <-> UTF-16 + экранирование протокола
           tgpagerengine.h
  data/    tgpager.rss/.loc      ресурсы (ASCII-плейсхолдеры, текст подменяется в рантайме)
  sis/     tgpager.pkg
```
